# 少女前线2（日服 / HaoPlay）抽卡记录导出工具

把你在游戏里的抽卡（采购）记录导出来，可以存成表格（Excel 能打开），也可以配合[查询工具](https://github.com/shrsheng/GF2-Gacha-Tracker)一起看。

**适用人群**：玩 **HaoPlay 日服** 的 PC 玩家，用**邮箱 + 验证码**登录游戏的账号。

---

## 一、先准备（只做一次）

1. 你的电脑是 **Windows**（本工具只支持 Windows）。
2. 下载本仓库：点页面右上角绿色的 **`Code`** 按钮 → **`Download ZIP`**，下载后**解压**到一个好找的文件夹，比如桌面。
3. 解压后文件夹里有一堆 `.bat`（蓝底齿轮图标）和 `.ps1` 文件，**不用管那些 `.ps1`**，你只会双击 `.bat`。

---

## 二、你想做什么？选一个

| 你的目的 | 双击这个文件 |
|---|---|
| 导出成表格（Excel 打开） | **`export_csv.bat`** |
| 拿到一串「网址 + 密钥」，贴到[查询工具](https://github.com/shrsheng/GF2-Gacha-Tracker)里看 | **`gettoken.bat`** |

> 如果「方式 A」哪天用不了了（弹出报错），再看第四节的「方式 B：开游戏抓取」。

---

## 三、方式 A：不用开游戏，输一次邮箱验证码

以 **导出表格** 为例（拿密钥给网页工具同理，只是双击 `gettoken.bat`）：

1. **双击 `export_csv.bat`**。会弹出一个黑色窗口，这是正常的。
2. 如果这是第一次用、或距离上次超过 **7 天**，窗口会让你：
   - **输入邮箱** → 打字输入你登录游戏用的邮箱，按回车。
   - 工具会给你的邮箱**发一封验证码邮件**。打开邮箱找到那串数字。
   - **输入验证码** → 把收到的数字打进去，按回车。
3. 之后它会自动把你 9 个池子的抽卡记录全部拉下来，存成一个表格文件（名字像 `gf2_gacha_日期.csv`），就在同一个文件夹里。用 **Excel** 或 WPS 双击就能打开。
4. 窗口里还会显示每个池子一共抽了多少、现在垫了多少抽。

> **7 天之内再用，不需要再输验证码**，双击就直接导出。超过 7 天才会再让你登录一次。

---

## 四、方式 B：开游戏抓取

如果方式 A 报错（比如游戏更新后登录方式变了），用这个。它需要**管理员权限**并且**打开游戏**。

1. **双击 `capture_csv.bat`**（或要密钥就双击 `capture_token.bat`）。
2. 会弹出一个窗口问你**是否允许以管理员身份运行**，点 **「是」**。
3. 按窗口提示，**打开游戏**，进到 **采购 → 记录**，随便翻一页。
4. 工具抓到后会自动导出表格 / 显示密钥。
5. 第一次用会自动下载一个约 30MB 的小工具，稍等一下属于正常。

---

## 五、配合查询工具使用（原作者的程序）

本工具只负责「拿到记录 / 拿到密钥」。如果你想要更漂亮的界面来看统计，可以用**原作者的程序**：

- 程序地址：**https://github.com/shrsheng/GF2-Gacha-Tracker**
- 介绍帖（巴哈姆特）：**https://forum.gamer.com.tw/C.php?bsn=70502&snA=3059**

用法：
1. 双击本工具的 **`gettoken.bat`**，它会显示一串 **`gachaUrl`** 和 **`Authorization`**，并**自动复制到剪贴板**。
2. 打开原作者的程序，在它的「同步设置」里把这两项**粘贴**进去，就能更新数据了。

## 六、常见疑问

- **会不会封号？** 这是读你自己的抽卡记录，低频使用（比如一周一次）风险很低。但别反复、频繁地登录或发验证码。
- **安全吗？会泄露我的信息吗？** 所有操作都在你自己电脑上完成，不会把你的账号、邮箱、密钥发给任何第三方。`auth.json`（里面是你的登录密钥）请**不要发给别人**。
- **弹出蓝色「Windows 已保护你的电脑」？** 点「更多信息」→「仍要运行」。（这是 Windows 对未签名脚本的常规提示。）
- **为什么要输邮箱验证码？** 因为游戏账号用的是邮箱+验证码登录，验证码只能你本人收，所以这一步没法自动，大约 7 天一次。
- **方式 A 报错怎么办？** 先试试方式 B（开游戏抓取）。方式 B 只要游戏能正常登录就一定能用。

## 七、里面都有什么文件（给好奇的人）

| 文件 | 作用 |
|---|---|
| `export_csv.bat` / `.ps1` | 方式 A：自动登录 → 导出表格 |
| `gettoken.bat` / `.ps1` | 方式 A：自动登录 → 输出密钥给网页工具 |
| `capture_csv.bat` / `.ps1` | 方式 B：开游戏抓取 → 导出表格 |
| `capture_token.bat` / `.ps1` | 方式 B：开游戏抓取 → 输出密钥 |
| `gf2lib.ps1` | 公共代码，上面几个都要用它，别删 |
| `登录流程.md` | 技术文档：登录原理与接口细节 |
| `auth.json` / `device.json` | 运行后自动生成，存你的登录密钥和设备标识（**勿外传**） |

> 本工具与原作者程序无从属关系，仅为方便获取记录的辅助脚本。
